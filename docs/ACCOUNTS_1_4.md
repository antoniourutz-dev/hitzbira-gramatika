# HitzBira 1.4 — private username account pilot

Username 3–24 characters; client and server append @hitzbira.app. No real mailbox or email recovery. Password minimum 12 characters and maximum 72 bytes. Earlier pilot email login remains available. One-use invitation required while shared-project legacy privileges remain under review. New Auth accounts use a server-selected isolated role, no corresponding database role; registration verifies role and direct API rejection before setting requested password. Gateway authenticates and checks account on each bounded read of the fixed HitzBira release. Service credentials server-side only. Private invite and account tables have no anon/authenticated grants. Local progress isolated by account UUID; guest and legacy keys retained; no cross-device sync yet. No general registration until broader security review. Existing legacy tables and policies unchanged. End-to-end registration remains to be tested with a trusted invite.
