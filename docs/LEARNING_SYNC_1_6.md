# HitzBira 1.6 · Biraren lorategia

Guest mode is restored with the exact previously published 1.4 snapshot; no newly approved academic content. Login is voluntary and manual accounts only. Account and guest storage separate by UUID. Optional guest import only on empty cloud account and explicit confirmation, retaining original local copy. Existing 1.5 account values are seeded only if cloud stream is absent; original seed is retained in journal even if ignored due to existing server state.

Six streams cover grammar attempts, goal, assessment history/seen, journey, verb attempts, verb path. Local durable outbox is written before account projection and synced via authenticated allowlist gateway. Server transaction locks user, deduplicates event UUID, merges additive counters and unions of completed items/history; goal/last feedback fields are last server-accepted changes. Completed assessments have unique run IDs; individual assessment/lab responses journaled separately. Pending events remain after failure/signout, replay at login and on network return. Account reset hidden and disabled to protect history. Server dates are Europe/Madrid receipt day; garden counts answered activities, not navigation or visits, shows seven-day flowers/current/best/total, never discards historical flowers. No points for clicks. Client-supplied practice data is learning telemetry, not official academic evidence or anti-cheat certification.

Limitations: simultaneous active tabs/devices show their own in-memory projection until next authenticated reload; server preserves additive events. Open in-progress exercise UI (draft text/queue positions) is not yet fully restorable; completed responses and exam picks are journaled. New sign-in/rehydration requires network. Local pending data is subject to browser storage quota/clearing/device loss before server acknowledgment; no absolute zero-loss guarantee. No backdated streaks on delayed upload. No direct access to student data tables or RPC for anon/authenticated roles. No password or real mailbox in progress journal. Prior snapshots already public in repository. Production unchanged.
